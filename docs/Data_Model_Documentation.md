# Data Model Documentation

## Verified model contents

The uploaded Power BI project contains eight tables:

- `Sales target (1)`
- `Order Details (1)`
- `List of Orders`
- `Orders Data`
- `Category Average Profit`
- `Monthly Sales Target`
- `Order Details Summary`
- `Sub-Category Total Amount`

The PBIX also contains a model diagram, confirming that the project includes a data-modeling layer.

## Analytical direction

The model supports a sales and profitability reporting workflow built around:

- Order-level and order-detail data
- Category and sub-category analysis
- Monthly sales targets
- Profit comparison
- Aggregated order-detail analysis

## Important scope note

This document records what was verified in the PBIX. It does not invent relationship cardinalities, KPI values, or business findings that were not verified from the source file.

## Intended report structure

The next report layer can use the model for:

1. KPI summary
2. Monthly sales trend
3. Sales by category
4. Profit by category
5. Sales versus target
6. Sub-category performance
7. Interactive slicers

## Portfolio value

This project complements an end-to-end dashboard by focusing on the less visible but important stages of analytics: preparing data and structuring a model for reporting.
